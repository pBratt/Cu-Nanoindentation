# Molecular Dynamics of Nanoindentation in Cu (001)

This repository contains the computational scripts, raw data, and visual analysis for an atomistic simulation of nanoindentation on a Copper (001) single crystal. The project successfully models the transition from Hertzian elastic contact to plastic yielding, capturing the homogenous nucleation of dislocations (the macroscopic "pop-in" event).

## 🛠️ Tools & Technologies
* **Simulation Engine:** LAMMPS (Large-scale Atomic/Molecular Massively Parallel Simulator)
* **Interatomic Potential:** Mishin (2001) EAM Alloy Potential for Cu
* **Data Analysis & Visualization:** MATLAB & OVITO (Dislocation Extraction Algorithm / Common Neighbor Analysis)

## 📂 Repository Contents
* `in.nanoindent` — The core LAMMPS input script defining the simulation parameters, thermodynamics, and indenter trajectory.
* `Cu01.eam.alloy` — The Embedded-Atom Method interatomic potential used to govern Cu-Cu interactions.
* `plotting.mlx` — MATLAB live script that parses the LAMMPS output to generate color-coded loading and unloading curves.
* `force_depth.txt` — Raw extracted data generated by the LAMMPS run.
* `Nanoindentation_Report.pdf` — The final compiled project report detailing the methodology, physical mechanisms, and visual evidence.
* `*.png` — High-resolution OVITO defect renders and the MATLAB force-displacement plot.

## 🔬 Key Results
1. **The Pop-In Event:** The MATLAB force-displacement curve captures a distinct vertical drop in force at exactly 4.0 Å depth. This represents the critical yield point where localized stress exceeds the theoretical shear strength of the perfect copper lattice.
2. **Dislocation Nucleation:** OVITO trajectory analysis confirms that at the exact timestep of the pop-in event, homogenous dislocation nucleation occurs. The pristine lattice breaks down, generating V-shaped dislocation loops and planar stacking faults that punch downward into the bulk material.
